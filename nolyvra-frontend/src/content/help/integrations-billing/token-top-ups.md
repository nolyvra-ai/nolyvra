## What it does

AI features (analysis, talent search, interview analysis) draw from a shared token balance
shown in the top bar. If you run low before your renewal date, you can buy a one-time top-up
pack instead of waiting.

## How to access it

Go to **Settings → Billing** and choose a token pack.
